# RabbitHole MCP vs Chrome + Playwright MCP

A comparison of two browsers driven by an AI agent over MCP: RabbitHole
**0.1.15** and Chrome with **Playwright MCP 0.0.85**. It measures what it costs
the agent to complete the same task with each one: tokens, tool calls, time
and correct answers.

**Measured:** 15 November 2026. **Source:** results supplied by the project
owner. These measurements were not rerun when this report was added to the
repository; raw runs and transcripts are not included with this report.

## Summary

| Test | What it measures | Correct, RabbitHole | Correct, Playwright | Tokens, RabbitHole | Tokens, Playwright | RabbitHole saving |
|---|---|---:|---:|---:|---:|---:|
| Test 1 — Fact lookup | Find three facts on Wikipedia | 3/3 | 3/3 | 16,345 | 50,251 | 67.5% |
| Test 2 — Interactive tasks | Six multi-step tasks | 18/18 | 18/18 | 139,169 | 215,661 | 35.5% |

Total tokens (input + output) per task: median of three runs for Test 1,
and the sum of the six per-task medians for Test 2.

## Test 1 — Fact lookup on Wikipedia (difficulty 2 of 10)

**What it is.** The agent must find on Wikipedia who created the Python
language, the month and year its development started, and the institution its
creator worked for at the time, and cite the URL it used. It may not use prior
knowledge or any tool other than the browser. It is a read-only task: open
pages and locate a fact.

**What it shows.** How much context each browser consumes for a simple lookup.

| Metric (median of 3 runs) | RabbitHole 0.1.15 | Chrome + Playwright MCP | Difference |
|---|---:|---:|---|
| Correct answers | 3/3 | 3/3 | — |
| Total tokens | 16,345 | 50,251 | 67.5% fewer |
| Input tokens | 15,821 | 49,335 | 67.9% fewer |
| Output tokens | 524 | 916 | 42.8% fewer |
| MCP calls | 2 | 6 | 4 fewer |
| Time (s) | 7.8 | 12.2 | 36% less |
| Cost per task (USD) | 0.0147 | 0.0289 | 49% less |
| Tool errors | 0 | 0 | — |

**Why RabbitHole wins.** It opens the page and searches it in a single call
(`open` with `find`), and returns only the passages that contain the search
terms. It solves the task in two calls: one Spanish page and one English page.

## Test 2 — Multi-step interactive tasks (difficulty 5 of 10)

**What it is.** Six tasks on two public test sites
([books.toscrape.com](https://books.toscrape.com/) and
[quotes.toscrape.com](https://quotes.toscrape.com/)). Each one exercises a
different browser capability, and the answer is graded automatically against
a known value.

| Task | What the agent has to do | Capability under test |
|---|---|---|
| `t1-ficha` | Open a category, find the cheapest of 11 books and read its detail page (title, price, UPC, stock) | Navigation and detail page |
| `t2-paginacion` | Walk a two-page category and aggregate data from 32 books | Pagination |
| `t3-javascript` | Read quotes the page generates with JavaScript and move to the next page | JavaScript execution |
| `t4-formulario` | Pick an author, wait for the tag dropdown to reload, pick a tag and submit | Forms with dependent fields |
| `t5-scroll` | Load all 100 quotes on an infinite-scroll page and report the last one | Dynamic loading on scroll |
| `t6-estrellas` | Count the 5-star books, a value that is not present as text | Information in attributes |

**What it shows.** Whether the browser holds up on real tasks with clicks,
forms and dynamic content, and what they cost.

| Metric (sum of the 6 per-task medians) | RabbitHole 0.1.15 | Chrome + Playwright MCP | Difference |
|---|---:|---:|---|
| Correct runs | 18/18 | 18/18 | — |
| Total tokens | 139,169 | 215,661 | 35.5% fewer |
| MCP calls | 20 | 21 | 1 fewer |
| Time (s) | 53.4 | 72.0 | 26% less |
| Cost (USD) | 0.1068 | 0.1065 | Approximately equal |
| Tool errors (18 runs) | 0 | 2 | — |

Per-task breakdown (median of three runs):

| Task | Correct, RabbitHole | Correct, Playwright | Tokens, RabbitHole | Tokens, Playwright | RabbitHole saving | Calls, RabbitHole | Calls, Playwright | Time, RabbitHole (s) | Time, Playwright (s) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `t1-ficha` | 3/3 | 3/3 | 36,137 | 38,963 | 7.3% | 5 | 5 | 10.7 | 10.9 |
| `t2-paginacion` | 3/3 | 3/3 | 15,928 | 26,520 | 39.9% | 2 | 2 | 6.3 | 9.0 |
| `t3-javascript` | 3/3 | 3/3 | 15,693 | 43,521 | 63.9% | 2 | 4 | 6.1 | 9.9 |
| `t4-formulario` | 3/3 | 3/3 | 33,482 | 54,320 | 38.4% | 6 | 6 | 12.9 | 15.6 |
| `t5-scroll` | 3/3 | 3/3 | 21,923 | 25,871 | 15.3% | 3 | 2 | 11.0 | 18.5 |
| `t6-estrellas` | 3/3 | 3/3 | 16,006 | 26,466 | 39.5% | 2 | 2 | 6.4 | 8.1 |

**Reading.** RabbitHole uses fewer tokens on all six tasks and is faster on
all of them. The dollar cost comes out approximately equal because prompt
caching makes the context Playwright re-reads on every call cheap.

## Why RabbitHole uses less

| Factor | RabbitHole 0.1.15 | Chrome + Playwright MCP |
|---|---:|---:|
| Tools exposed | 12 | 25 |
| Size of the tool definitions | 6,685 characters | 21,177 characters |
| Fixed context on every model call | About 4,400 tokens | About 8,100 tokens |

The agent re-reads that fixed context at every step, so the difference is
multiplied by the number of calls.

## How it was measured

- **Agent:** Claude Code in non-interactive mode with the `claude-sonnet-5-5`
  model. Every run is a fresh session with no memory of earlier ones.
- **Tools:** the agent only has the MCP browser of its arm. No terminal,
  no web search, no other tools.
- **Same conditions:** same prompt, same model and same machine for both
  browsers, with runs interleaved.
- **RabbitHole:** `rabbithole mcp --ephemeral` (in-memory profile).
- **Playwright:** `@playwright/mcp` 0.0.85 with headless Chrome and an isolated
  profile.
- **Repetitions:** three runs per task and browser. The median is reported.
- **Grading:** automatic against known answers, and reviewed in the transcripts.
- **Date:** 15 November 2026.

## Limitations

- Three runs per cell: the figures are indicative, not a statistical result.
- The Test 2 sites are simple test sites, with no logins and no anti-automation
  protection.
- Results depend on the model and the agent: with another model the number
  of calls may change.
