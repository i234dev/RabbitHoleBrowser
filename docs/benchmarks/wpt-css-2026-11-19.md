Compared with the 18 November baseline, 934 tests pass newly. The main gains
are css-masking (+164: `clip-path` basic shapes, `url()` clip paths, legacy
`clip`), grid (+322), flexbox (+154), sizing (+105), filter-effects (+24),
CSS2 (+71) and css-fonts (+11: `font-stretch` matching).

Three tests that passed on 18 November fail now:
`clip-path-animation-non-keyframe-timing-function`, `rotate-transform-equivalent`
and `individual-transform-ordering`. They passed only because animations were
not rendered, so test and reference showed the same static boxes; they need
3D matrix interpolation and separately animated `translate`/`rotate`/`scale`.

Of the 141 tests reported as failing since 13 November in the previous record,
87 are errors ("reftest-wait did not clear"), not pixel failures: the earlier
runner captured the page even when the wait timed out. 55 of them load support
files that the sparse WPT checkout does not contain.
