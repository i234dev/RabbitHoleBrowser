# WPT web APIs: 0.2.45 against 0.1.44 (23–24 November 2026)

The 0.2.45 engine (source `de718d24`) passed **1,534,634 / 1,756,838
subtests (87.35 %)** on the 38,226 natively discovered browser testharness
URLs of WPT `831baf28d226911e47b2454d69e0c9e7348dd4d1`. On the same URLs the
0.1.44 reference (`a43c8e0`) passed **771,080 / 1,752,285 (44.0 %)**.

## Conditions

TheOtherSide (i7-12700H, WSL2), Cargo profile `ci`, `rh-wpt` (sha256
`583ffe76…`) run directory by directory on the full checkout of the pinned
WPT revision: 279 top-level directories, ten jobs on CPUs 0–3 and 10–15,
timeouts of 5 s (15 s for long tests), 2,500,000 KiB per page, local HTTP
inside a loopback-only network namespace. The run started on 23 November at
22:41 and finished on 24 November at 00:40 (Europe/Madrid). The reference
results are the 0.1.44 run of the [complete measurement of
23 November](wpt-apis-2026-11-23-367874b4.md), under the same conditions.

The comparison pairs every page by URL and every result by subtest name and
multiplicity. Server ports that appear in subtest names are normalized. A page
without subtests counts once by its harness status. The 1,946 manifest
variants previously served by upstream wptserve were not rerun; the totals
cover only the native pages.

The delivery adds one engine change after `de718d24`: Windows UDP
port-unreachable reports are no longer fatal for WebRTC
(`14648833`, `crates/rtc`). Linux does not raise these errors on the
unconnected sockets used here.

## Losses against 0.1.44

Of the 10,520 lost subtests, 4,722 are CSS Transitions checks. The largest
groups are interpolation and composition tests of properties without an
animation implementation: css-gaps 2,394 (rule insets and colors), css-masking
1,664 (`mask-border-*`), motion 1,294, css-values 797 (`calc-size()`) and
css-text 836. In 0.1.44 these properties were not recognized and both sides of
each comparison serialized identically; now the properties are recognized
and the interpolation results are compared. css-view-transitions loses 360
CSSOM checks: assigning `::view-transition` pseudo-elements to `selectorText`
is now rejected; stylesheet parsing is unchanged.

## Same-origin frame assignment fix

The first full run of the integrated tree (18:20–20:23 on 23 November, before
`de718d24`) found six pages of `quirks/` that timed out with no results. They
assign elements to a same-origin frame's window, which threw `DataCloneError`.
With the fix, `quirks/` returned to 6,627 / 6,984, and the final run gained
6,549 and lost 9 subtests against that first run.
