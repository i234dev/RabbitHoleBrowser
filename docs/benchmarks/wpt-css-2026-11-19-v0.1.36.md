## Changes in measurement conditions since the 0.1.35 record

- **Runner:** with several `rel=match` references, a test now passes when any
  of them matches, and every `rel=mismatch` reference must mismatch, as the
  WPT documentation specifies ("Multiple References"). The runner used to
  require every match reference to match. On the 0.1.35 layout code (`7b94b53`)
  this change alone gives 13,351 instead of 13,330: +23, −2.
- **Support files:** the sparse WPT checkout now also contains `/media/`,
  `/dom/events/scrolling/` and `/web-animations/`, which some CSS tests load.

The gain attributable to the 0.1.36 engine changes, measured with the
corrected runner on the same checkout, is 13,351 → 14,993 (+1,642).

Main changes: UAX #14 line breaking, justification, hyphenation and text
decoration skip-ink (css-text +337); `::first-letter`, floats, tables, sticky
and relative positioning (CSS2 +563); border-image, conic and tiled gradients,
gradient colour interpolation, SVG images at their drawn size, EXIF
orientation, line-clamp, overflow-clip-margin and OpenType font features
(backgrounds +234, images +230, overflow +100, fonts +65).

About 25 tests that passed with 0.1.35 fail now. Almost all passed by
coincidence: test and reference were equally wrong until one of the features
they use started to work. These are 9 `lch` hue gradients (wide-gamut colours
are clipped to sRGB), 10 `text-spacing-trim` tests (their references now apply
`font-feature-settings: 'halt'`), 2 container-relative units (`cqw`), and single
tests for `::selection`, container queries during layout, Korean jamo (no font
on the measuring machine), a sticky box in a nested scroller and the fuzzy
limit of `invert-scale`.
