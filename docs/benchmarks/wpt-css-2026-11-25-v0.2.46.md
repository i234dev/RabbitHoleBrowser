All 19,627 CSS reftests of the committed corpus, measured on **25 November

**16,576 / 19,627 (84.5 %)**; 0.2.45 had 16,435. Compared test by test with the
failures recorded for 0.2.45, 145 tests now pass: css-grid 88, css-contain 13,
css-writing-modes 10, CSS2 6, css-position 5, css-fonts 5, css-sizing 3, and
two each in css-text, css-overflow, css-masking, css-flexbox and css-box.

Four tests that passed with 0.2.45 fail. In each, the test or its reference
uses multi-column layout, which 0.2.45 ignored, so both sides rendered the same
single column:

- `css-align/blocks/align-content-block-overflow-000`: the root element is a
  multi-column container; the `unsafe center` and `unsafe end` cases, which
  are not implemented, used to fall outside the 600 px viewport.
- `css-grid/grid-lanes/gap/grid-lanes-gap-002`: with real intrinsic sizes of
  the multi-column items, grid lanes assign different track widths in the test
  and in the reference.
- `css-position/multicol/vlr-ltr-rtl-in-multicols.tentative` and
  `vrl-ltr-rtl-in-multicols.tentative`: absolutely positioned boxes whose
  containing block is an inline split across vertical columns.
