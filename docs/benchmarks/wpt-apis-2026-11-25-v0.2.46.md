# WPT web APIs: 0.2.46 against 0.2.45 (25 November 2026)

The 0.2.46 engine (source `7b235dfb`) passed **1,578,581 / 1,757,120
subtests (89.84 %)** on the 38,226 natively discovered browser testharness URLs
of WPT `831baf28d226911e47b2454d69e0c9e7348dd4d1`. The 0.2.45 run of the

(sha256 `70d3c667…`) run directory by directory on the full checkout of the
pinned WPT revision, 279 top-level directories, ten jobs on CPUs 0–3 and

not run.

`@font-face` rules like the browser, as the reftest runner already did and as
WPT expects. Pages that measure text in Ahem now run as written.

The comparison pairs every page by URL and every result by subtest name and
multiplicity, with server ports in names normalized.

## Losses against 0.2.45

All 35 lost subtests were examined:

- 15 passed by coincidence and now reach code that is incomplete:
  `css-transitions/properties-value-inherit-003` (6: border widths,
  `line-height` and `vertical-align` are now animatable and children start
  their own transitions while the parent's `font-size` transitions, as
  `padding` already did); shape and motion `path()` interpolation (4: the
  transition now starts; segment types are not preserved); two MathML
  operator spacing checks (the page's web font now loads and exposes missing
  operator spacing); `scroll-animations/css/view-timeline-lookup` (`z-index`
  is now animatable; `animation-timeline` is not implemented); two
  Content-Security-Policy checks (CSP is not implemented; the `srcdoc`
  resources now load with the parent's base URL).
- 6 `subresource-integrity/signatures/tentative/authority` names contain a
  port-dependent signature; the equivalent subtests pass under their new
  names.
- 5 `css-break/table/repeated-section` tentative checks: tables are monolithic
  inside columns.
- 3 `input-events`: two typing checks fired `input` without a DOM change, which
  the specification does not allow; `execCommand("justifyLeft")` now follows
  the specification expected by `editing/data/justifyleft.js`.
- 1 `css-conditional/container-queries/counters-flex-circular`: the subtest
  name contains a measured width, which is now the correct 150.
- 5 timing-dependent pages, unchanged when repeated in isolation
  (render-blocking scripts 3, `IndexedDB/interleaved-cursors-small` and
  `workers/Worker_terminate_event_queue`).
