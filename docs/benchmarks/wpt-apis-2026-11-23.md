## Corpus and execution

The private full checkout on TheOtherSide came from WPT `831baf28d226911e47b2454d69e0c9e7348dd4d1`. Its manifest contains 40,250 testharness URLs, including 78 shell-only variants. The API run used native discovery for 38,226 manifest browser URLs, supplemented with 1,946 additional browser variants served by upstream wptserve. Both paths used the same revision's RabbitHole child browser to run the tests. Sixteen native discovery extras were excluded from the published counts. All source trees were available, including the entire HTML, workers, media and CSS API trees. The directory appendix lists all measured areas. The shared sparse checkout continued supplying the original CSS reference corpus.

The machine was an Intel Core i7-12700H under WSL2. Both API engines used the Cargo `ci` profile, an 800 × 600 viewport, bundled fonts, 2,500,000 KiB per page and local HTTP inside a loopback-only network namespace. Timeouts were 5 s or 15 s for long tests with up to 8 s for parent termination and reporting. The candidate measured encoding first so its largest verified change could be checked early. Each top-level native directory started a fresh runner and server. Native runs used ten workers, upstream-server runs used six, with combined CPU affinity 0–3 and 10–15. The audit keys each pass on its browser URL, complete test name and multiplicity. It matches an assigned server port only when the same page names that exact loopback host and port in a URL. Generated host-only names and deliberately malformed origin strings retain their original case and punctuation. For example, the CORS fixture formats its assigned host in both uppercase and lowercase and with zero, one or two slashes. The audit preserves each form as a distinct subtest. The fetch fixture records both server endpoints, so each port is matched to its own role. The raw comparisons retain all original names.

## What changed

Legacy form navigation explains most of the gain. Scripted forms that target a named child frame now load their encoded request in that frame. The calling page can read the current same-origin frame's query string. An intermediate full native `encoding` run on `6876b713` improved from 236,429/791,733 to 790,602/791,566 with zero previous passing names lost. There are thousands of independently tested characters per encoding. Those checks share one form-navigation prerequisite, so their contribution to the global rate is larger than the number of distinct APIs changed.

## Remaining causes and user impact

The priority order below is based on the behavior affected. It is an engineering assessment. WPT weights each subtest equally and does not measure usage frequency on real sites.

1. **Editors and form interactions.** The frame bridge cannot expose a live Range from another realm. Rich-text editing commands also use fixed responses, so content and selection state can diverge.
2. **Styling and component behavior.** Computed color serialization, CSSOM serialization, reflected HTML attributes and popover target references account for repeatable groups. They affect styles read by scripts and state shared between DOM properties and attributes.
3. **Storage, network requests and background work.** IndexedDB exception ordering, byte streams, service-worker support and origin-dependent fixtures affect asynchronous application logic. The native HTTP server can serve Python handler source. The upstream replay of the cache fixture on the reference improved from 0/26 to 26/26. This distinguishes server limitations from HTTP cache behavior.
4. **Cryptography, media and device access.** Unsupported algorithm dispatch and key usage checks affect cryptographic operations. Device capture, trusted TLS, licensed DRM and real hardware have additional prerequisites. The loopback HTTP corpus cannot establish Widevine or device interoperability.

The service-worker registration path rejects module scripts. The Web Audio implementation returns undefined for audioWorklet, and MediaSource reports that dedicated-worker construction is unavailable. The clipboard stores items within the realm, permissions use a fixed descriptor/state table and notifications resolve permission requests as denied. Separately, the local testdriver lacks permission-setting support. Device or permission-dependent results therefore need controls appropriate to those features.

The WebAssembly JS binding accepts numeric table limits but rejects the BigInt limits in the 64-bit table descriptor used by the WAST default import registry. Many core cases subsequently report missing import modules or absent exports. In an isolated diagnostic namespace, omitting the unused 64-bit table fixture let the unchanged reference and candidate pass 336/336 alignment checks and 160/160 annotation checks on both replays. The unmodified reference scored 314/336 and 154/160, respectively. Only the unmodified corpus supplies the published counts.

In the contenteditable paragraph-join fixtures, WebDriver supplies Backspace or Delete and then checks the resulting DOM. The headless keyboard path returns before editing contenteditable elements. It therefore leaves the original paragraph boundary and whitespace in place. This is separate from the fixed return value of document.execCommand. [Keyboard default actions](../../crates/engine/src/frames.rs)

For SVG graphics, the hit-test list records element rectangles. The computed pointer-events type represents only auto and none. The SVG fixture probes a rectangle’s fill and stroke separately, and tests a text glyph against both. Interactive SVG controls can select the wrong element under the pointer. [Computed style](../../crates/style/src/computed.rs) and [paint hit testing](../../crates/layout/src/display_list.rs)

The key derivation fixtures generate an ECDH private key to exercise the wrong-key path in HKDF and PBKDF2. The implementation rejects ECDH generation. The fixture catches that rejection, supplies a null key, then gets TypeError from the CryptoKey brand check. The affected assertions thus share an ECDH setup dependency. [WebCrypto key handling](../../crates/script/src/js/crypto.js)

In the generated mixed-content cases, the fixture checks server state through a separate JSON request. A null response reaches its status check before it can compare the policy result. This diagnostic does not determine whether the underlying request was blocked. For media capture, the engine exposes getUserMedia and returns NotSupportedError before supplying a stream. Web Audio implements several oscillator, gain and buffer-source operations and has no global ConstantSourceNode constructor. [Capture binding](../../crates/script/src/window.rs) and [audio node bindings](../../crates/script/src/js/webaudio.js)
