## Corpus and execution

The complete source archive for WPT `831baf28d226911e47b2454d69e0c9e7348dd4d1` was extracted into a private tmpfs on TheOtherSide. This materialized every directory at that revision, leaving the shared sparse checkout available for the 19,627-case CSS comparison. The shared checkout originally contained `css`, `fonts`, `resources`, `images`, `common`, `support`, `web-animations`, `dom/events/scrolling`, `media`, `selection` and `service-workers`. The API run includes the complete trees for all of those directories and the additional top-level areas in the directory results.

The upstream manifest generator ran locally with downloads disabled. Its testharness inventory has 40,250 URLs, including 78 marked `jsshell`. The browser denominator is **40,172 URLs**. Each URL includes its global and query variant.

Both runs use the Cargo `ci` profile, an 800 × 600 viewport, bundled fonts, a 2,500,000 KiB address-space limit per page, a 5 s timeout and 15 s for long tests. The parent allows up to 8 s more for termination and reporting. The workers run on the Intel Core i7-12700H under WSL2 with affinity to CPUs 0–3 and 10–15. Build and conformance jobs can share those CPUs. Each server and its browser children share an isolated network namespace with loopback as its only interface. The engine loads test pages over HTTP on loopback. Secure-origin checks, actual TLS handshakes, HTTP/2, HTTP/3, real devices and external services have different prerequisites.

The supplemental server serves the pinned WPT wrappers and handlers. Its two reporting resources are the same RabbitHole harness reporter and testdriver adapter used by the native run. Sixteen extra URLs found only by native discovery and the 78 shell entries are excluded from browser totals. The queryable URL inventory, per-page JSONL, guard reports, binary hashes and time logs are retained with this run's evidence.

The runner counts a page that reports zero named subtests as one result, passing only for harness status OK. A timeout can prevent later subtests from being registered. The before and after denominators can therefore differ even when every URL was attempted. The regression audit uses full subtest names and checks for disappeared passes.

## Confirmed causes from the reference

| Priority for ordinary sites | Cause and evidence | User-visible effect |
|---|---|---|
| High | The same-origin frame bridge can return Nodes and serialized values, but a live Range has no foreign-object representation. The five Range mutation pages report 4,176 failures at the check for a Range from the child frame. | Rich-text editors and document tools that access live objects across frames. The number is a count of failed checks sharing a prerequisite. |
| High | FormData previously stringified file entries and moved a replaced field to the end. The multipart encoder grouped fields before files. | Binary uploads, mixed text/file payloads and form processors that depend on entry order. |
| High | XHR accepted invalid method and header arguments. File and Blob conversion also lost byte-view boundaries, MIME information or file metadata. | Request construction and retry logic, file previews and uploads, worker processing of binary data. |
| Measurement infrastructure | The native server checks for static files before its unsupported-Python-handler fallback. A present handler with no native implementation can return its Python source. On the unchanged reference binary, switching the cache-status fixture to the upstream server changed 0/26 to 26/26. For the origin fixture the first two subtests changed from FAIL to PASS, then both runs timed out. | These rows cannot establish the browser's HTTP caching or origin behavior by themselves. |
| Environment-dependent | Tests that require a local TLS trust anchor, hardware permissions, real-time media devices or a licensed CDM need capability-specific infrastructure. | Capture and DRM interoperability require additional evidence. Widevine requires a separately supplied CDM. |

## Engine changes under review

| Revision | Behavior and regression coverage | Review risk |
|---|---|---|
| `9b67842c` | Blob and Fetch text and JSON readers consume one leading UTF-8 signature. Tests cover consecutive signatures and JSON beginning with a signature. | Text and JSON consumers share decoding behavior. Binary consumers must retain the original bytes. |
| `aa0d13fd` | Blob construction copies byte views, preserves MIME information and observes iterator and property-bag conversion order. | Getters can modify backing buffers or throw. Tests exercise these side effects. |
| `acc30b18` | Fractional Blob slice offsets use Web IDL nearest-even clamping. | Both ends of a slice must handle negative half-integers consistently. |
| `d7e14551` | File construction preserves name, MIME type and last-modified time, including subclass construction. | Observable conversion order and integer conversion affect user-defined getters. |
| `a0305451` | Multipart encoding preserves alternating fields and files, normalizes text newlines and escapes disposition parameters. | Changes exact upload bytes. Binary payloads must survive unchanged. |
| `c0d39bb4` | FormData stores actual File objects and keeps the first matching entry in place on replacement. | Native entries must retain live files under GC and release removed references. |
| `c96279ec` | Dedicated and shared workers receive FileReaderSync. Restarting a read in an event handler cancels events from the prior read. | Synchronous reads allocate a copy. Handler reentrancy changes delivery order. |
| `1276ddb8` | XHR validates method tokens, header arguments and state with the specified exception ordering. | Code that depended on accepting invalid requests can now throw synchronously. |
| `b048c5df` | Iterators and forEach on FormData and URLSearchParams observe mutations to the underlying entry list. | Deleting and appending while iterating affects indices. An exhausted iterator must stay exhausted. |
| `46c0316d` | Structured cloning preserves Blob and File bytes, MIME, metadata and shared references in the cloned graph. | The byte payload is encoded into the bridge representation. Large objects require extra memory during cloning. |
| `8ac63d97` | FileReader validates the Blob and converts the encoding before entering the loading state. Blob sequences use the engine's existing length limit. | Conversion failures must unwind an iterator and leave the reader available for subsequent use. |

The API regression tests are in `crates/script/src/tests_webapi.rs`. The multipart wire-format test is in `crates/net/src/fetch.rs`. The native form submission entry point still accepts separate text and file lists. Programmatically constructed FormData uses the ordered representation.
