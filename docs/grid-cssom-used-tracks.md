# Final Grid tracks in CSSOM

Unvalidated follow-up to the separate named-line candidate `98d1668`, based on
published 0.1.16. No compilation, runtime, WPT pass or performance result has
been inferred from static inspection. Original candidates and corpus remain
unchanged.

## Representation and ownership

`UsedGridTrackList` is a shared style-crate data type, requiring no dependency
between script and layout. A real Grid box retains an immutable `Rc` result
for each logical axis after final sizing and item layout. Standalone results
contain actual used pixel sizes and authored line-name sets. Subgrid results
contain only its explicitly specified local name sets, expanded/truncated to
its actual inherited line count. Empty sets remain significant for subgrid.

Placement still uses all line names, including those generated by named areas.
CSSOM metadata retains authored names separately so generated area names do not
leak into the serialized template. Leading/trailing implicit tracks extend
this metadata alongside the placement list. The result includes collapsed
zero-size tracks and implicit tracks, without reconstructing sizes from CSS.

Grid lanes publish their completed grid axis. Their ignored stacking-axis
template uses computed syntax. A writing-mode wrapper remains anonymous; the
query follows the actual owning element box, whose columns and rows are
already expressed in that element's logical axes.

The additive HostEnv queries force fresh layout and return the immutable
result. A frame query identifies the actual document, uses the existing frame origin check,
updates the direct child's viewport and flushes its layout. Same-origin
ancestor and descendant paths remain separate. No query chooses a frame by
NodeId alone.
The existing origin policy is unchanged; this patch does not claim to repair
opaque-origin, sandbox or cross-origin WindowProxy behavior.

## Measurement and cache boundary

An RAII depth guard suppresses publication during intrinsic calculations and
Grid/Flex/table/writing-mode item measurements. The layout cache records this
distinction: a measurement cache cannot replace final layout, and a final
cache cannot silently stand in for a measurement. Final cache reuse retains
the immutable result. Measurement never replaces a previously final result.

`LegacyIndefinite` explicitly produces no completed CSSOM axis. Its computed
fallback stays distinguishable from a published used list. This does not turn
the unfinished orthogonal dispatcher into an implemented feature.

Captured metadata is charged through the existing cumulative Grid work budget
before copying sizes and names. Authored name lists are shared between copied
track lists. No new claim about GUI panic handling or overall layout resource
limits is made.

## Serialization and no-box fallback

Only `grid-template-columns` and `grid-template-rows` gain this query. The
standalone serializer lists each used track in pixels and combines adjacent
names as sets. The subgrid serializer preserves every local line, including
empty trailing sets. Identifiers are escaped, and duplicates on the same line
are serialized once. Elements without a Grid box use computed track syntax,
retaining percentages and compact repeats rather than inventing used sizes.

The contracts are [Grid2 §7.2.6](https://drafts.csswg.org/css-grid-2/#resolved-track-list),
[§7.3.2](https://drafts.csswg.org/css-grid-2/#implicit-named-lines) and the
[Grid3 stacking-axis rule](https://drafts.csswg.org/css-grid-3/#grid-template).
